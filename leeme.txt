### BLOQUE 1: INGENIERÍA DE CONTEXTO (El "Cerebro")

*Copia y pega esto **SIEMPRE** al inicio de cualquier chat con ChatGPT/Claude/Gemini para que entienda tu App.*

```markdown

ESTOY CONSTRUYENDO: Una App educativa de inglés (EnglishStudio) sin dependencias de UI externas.
STACK: React + Vite + Tailwind CSS + Lucide React.

REGLAS DE DISEÑO (ESTRICTO - NO MODIFICAR):
1.  **Contenedores:** Siempre `bg-white` (o colores pastel muy suaves), `border-4` (4px), `border-slate-900` (o color oscuro saturado), `rounded-[2.5rem]` (muy redondeado).
2.  **Sombras:** SIEMPRE Duras y Sólidas. Formato exacto: `shadow-[8px_8px_0px_0px_rgba(15,23,42,1)]` o similar con color hex. NUNCA usar sombras difuminadas (`shadow-lg` estándar de Tailwind NO).
3.  **Tipografía:**
    - Títulos: `font-black uppercase italic tracking-tighter` (Inter/Sans).
    - Cuerpo: `font-bold` o `font-medium`.
    - Lectura: `font-serif` (solo para textos largos).

5.  **Colores:**
    - Estructura: Slate-900 (Negro azulado).
    - Acentos: Indigo-600, Fuchsia-600, Amber-400 (Amarillo eléctrico), Emerald-500.
    - Fondos: Slate-50, Indigo-50, Rose-50 (Pasteles).

REGLAS DE CÓDIGO:
1.  Usa `lucide-react` para iconos.
2.  No uses librerías externas (Framer Motion, Styled Components). Usa clases nativas de Tailwind (`transition-all duration-300`, `animate-in zoom-in`, etc.).
3.  El componente recibe props: `({ data })`.

Si entiendes este Sistema de Diseño, responde solo: "SISTEMA CARGADO: LISTO PARA PROGRAMAR".
```

### ✅ Checklist para validar lo que te entregue la IA

Antes de copiar y pegar el código que te genere la IA, revisa estos 3 puntos. Si falla uno, dile "Corrige esto":

1. **¿Las sombras son `shadow-lg` o `shadow-[...]`?**
* ❌ Mal: `shadow-lg` (se verá borroso).
* ✅ Bien: `shadow-[8px_8px_0px_0px_#000]`.


2. **¿Los bordes son `border` o `border-4`?**
* ❌ Mal: `border` (muy fino).
* ✅ Bien: `border-4 border-slate-900`.


3. **¿Usa `data.activeRules` o inventó nombres nuevos?**
* El JSON debe coincidir exactamente con las props que esperan tus componentes (`activeQuiz`, `vocabulary`, etc).
